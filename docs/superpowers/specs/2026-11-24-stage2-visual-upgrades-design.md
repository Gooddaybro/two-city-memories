# 双城约会纪念册 · 第二阶段（拉颜值与仪式感）设计规范

- **日期**：2026-11-24
- **前置基线**：第一阶段模块化架构（`e0a4354`，已含 7 张 WebP 真实照片与 2 份头像）
- **所属阶段**：三阶段规划中的 **第二阶段（子项目 2：拉颜值）**

---

## 1. 目标与范围

1. **顶栏「双城实时同屏」天气与天色**：首屏上方极简双城实时天气条，直连免 Key 的 Open-Meteo API 展示北京与连云港实时气温、天气、温差与俏皮提醒，并按昼夜时段柔和调节首屏环境光晕。
2. **动态双城轨迹地图（C 位）+ 里程数据面板 + 约会灵感卡**：
   - 轻量自定义 SVG 华北–华东海岸轮廓版图 + 真实经纬度投影；
   - 自动根据车票数据绘制微光流动的高铁贝塞尔航线（已检票实线流光、待出票虚线微光）；
   - 点击城市光点弹出浮窗，联动展示该城车票详情与对应 WebP 照片（点图可打开灯箱）；
   - 自动统计累计总公里数、已检票车票数、共同打卡城市数、心愿完成率，进入视口触发 Count-up 数字滚动递增；
   - 旁边内嵌轻量化“下次约会去哪 / 吃什么”互动刮刮乐/灵感抽取卡。
3. **拟真复兴号磁介质高铁票 + 检票盖章动效**：
   - 蓝/粉双色复兴号磁介质票面（车次号、出发站⇄到达站、检票口/座位、确定性虚拟二维码 SVG 与票根条码）；
   - 状态切换为 `已检票` 时触发红色/鎏金圆形检票印章盖章微动效。
4. **克制的听觉与微动效氛围**：
   - 右下角（避开手机底部导航）迷你旋转黑胶唱片机，**默认静音不自动播放**；内置温暖 Web Audio 八音盒/电钢和弦循环（零外链失效，歌单含 10.05 彩蛋曲目名《我爱你 · 暖夜八音盒》），同时预留 `assets/audio/` 本地 `.mp3` 替换能力；
   - 全局轻量级滚动渐显（遵循 `prefers-reduced-motion`）+ 仅在勾选完成心愿时触发的 1.2 秒金色微粒撒花。

---

## 2. 新增与变更模块

- `js/utils/stage2-logic.js`：纯函数模块（零 DOM 依赖，全量单元测试）：天气码解析、温差提醒文案、昼夜天色判断、经纬度投影、航线贝塞尔路径、里程与城市聚合统计、车票元数据补全、约会灵感抽取。
- `js/modules/weather.js`：Open-Meteo 实时天气请求（15 分钟 `sessionStorage` 缓存 + 离线降级）、双城天气条渲染与首屏天色光晕同步。
- `js/modules/map.js`：SVG 轨迹地图渲染、城市节点浮窗（含照片点击触发灯箱回调）、Count-up 里程数据面板与约会灵感刮刮卡。
- `js/modules/tickets.js`：升级为拟真复兴号蓝/粉磁介质车票、支持新增时填写车次/里程/票面色调、支持检票盖章微动效。
- `js/modules/vinyl.js`：迷你旋转黑胶唱片机 UI + Web Audio 柔和合成引擎 + 可选 `assets/audio/` 真实音频优先探测。
- `js/modules/effects.js`：克制滚动渐显 `IntersectionObserver` + 心愿完成金色微粒 Canvas 撒花。
- `assets/audio/README.md`：说明如何放入自定义 `.mp3` 替换默认八音盒旋律。
- `tests/stage2.test.mjs`：覆盖 `stage2-logic.js` 与 `schema.js` 新车票字段的单元测试。
