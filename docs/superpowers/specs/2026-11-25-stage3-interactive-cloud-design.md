# 双城约会纪念册 · 第三阶段（强互动与云端秘密基地）设计规范

- **日期**：2026-11-25
- **前置基线**：第二阶段完整静态版（`9968f9a`）
- **核心架构**：方案 A —— Supabase Postgres（RLS 锁定）+ 统一 Edge Function 网关（`two-city-api`）+ **双 iPhone Bark（APNs）主力推送** + 前端本地试玩/云端无缝切换

---

## 1. 核心功能与交互设计

### 1.1 浏览免锁 + 双人身份认领（密码 `0808`）
- 访客打开纪念册可直接浏览全部公开内容，无登录墙阻力。
- 顶栏右侧新增身份按钮（未认领显示 `认领身份`，认领后显示 `🐶 许金阳` 或 `🐷 渐姝君` + 本地/云端状态点）。
- 点击认领弹窗选择身份（许金阳 / 渐姝君）并输入口令（默认 `0808`）：
  - **云端模式**：调用 `POST /auth/claim`，服务端校验 `COUPLE_SECRET` 后签发 HMAC-SHA256 会话令牌存本机，后续免重输；
  - **本地体验模式**（未填云端 API 地址时）：本地校验 `0808` 即可完整试玩全部第三阶段交互。
- 未认领状态点击发送信号、写时光胶囊、换心情或改心愿时，自动唤起认领弹窗引导输入 `0808`。

### 1.2 今日心情状态贴纸
- 展示在「关于我们」许金阳与渐姝君双人档案卡顶部。
- 预设 6 枚轻量贴纸：`🔬 实验室搬砖`、`🌊 看海吹风`、`🍜 想吃好吃的`、`💓 超级想你`、`📚 认真搞科研`、`🌙 准备睡啦`，支持附加一句自定义短状态（≤ 24 字）。
- 已认领身份后可一键切换自己的心情贴纸并实时同步给对方。

### 1.3 双城信号发射器（戳一戳）+ 心跳墙 + 一键回抱
- 4 枚暗号胶囊：`🐾 突然想你`、`🍜 催你干饭`、`🫂 远程充能`、`🌙 晚安信号` + 可选 20 字手写纸条。
- 点击发射触发跨城微光脉冲波纹，并更新「本周互戳 / 累计互戳」计数与「双城心跳墙」（展示最近 12 条信号纸条）。
- 每条对方发来的纸条右下角支持**一键回抱/回戳**。
- 云端模式下自动调用 **Bark APNs** 秒级推送到另一半的 iPhone 锁屏（许金阳发 → 推渐姝君 iPhone；渐姝君发 → 推许金阳 iPhone），通知附带双城图标并支持点击直达线上纪念册，服务端内置 10 秒防连点节流。

### 1.4 火漆封印 · 时光胶囊定时信箱 + 摇一摇暗号 + 贴纸盖章回执
- 位于「双城来信」板块内，通过双页签自由切换「双城长信」与「时光胶囊信箱」。
- **寄出胶囊**：选择火漆印章（`08·08` / `🐶×🐷` / `🚄`）、信封标题、拆封前暗号提示（`teaserHint`）、解锁时间（`unlockAt`，支持快捷选“下次见面/跨年夜/自定义”）与正文。
- **未到期状态**：立体暗红/鎏金火漆封印信封 + 精确倒计时；点击火漆触发**轻晃动效并弹出 `teaserHint` 暗号提示**，绝不泄露正文（云端模式下服务端直接置空未到期正文，真·防 F12 偷看）。
- **到期拆封**：点击触发**火漆碎裂动效 + 信纸缓缓展开**；收件人读完可盖一枚贴纸回执（`💓 已读心动` / `🫂 收到抱抱` / `🥹 看哭了`）并写一句短评（≤ 40 字），同步并推送通知给寄件人。

### 1.5 心愿清单云端双向同步 + 专属印记
- 每条心愿自动展示创建者印记（`🐶 小狗` / `🐷 小猪` / `双城`）。
- 任意一方新增或勾选完成心愿（保留金色微粒撒花）时，自动同步云端并向另一半 iPhone 发送一条温柔 Bark 提醒。

## 2. 后端与数据规范

- **`supabase/schema.sql`**：建 4 张表（`couple_moods`、`wishes_sync`、`capsule_letters`、`love_signals`），全部启用 RLS 禁止 `anon` 直接读写。
- **`supabase/functions/two-city-api/index.ts`**：统一 Deno Edge Function 网关，提供：
  - `GET /health`
  - `POST /auth/claim`（校验 `COUPLE_SECRET`，默认 `0808`，签发 HMAC-SHA256 token）
  - `GET /sync`（返回聚合状态；对 `now < unlock_at` 的胶囊隐藏 `body`）
  - `POST /mood`、`POST /signals`、`POST /wishes`、`POST /wishes/toggle`、`DELETE /wishes/:id`、`POST /capsules`、`POST /capsules/open`、`POST /capsules/receipt`
  - 统一 `pushToPartner(senderPartner, title, body)` 封装 **Bark APNs 推送**（`BARK_KEY_XJY`、`BARK_KEY_JSJ`，支持自定义图标与点击跳转 URL）。
- **`data/cloud-config.js`**：仅存公开的 `apiBaseUrl`（留空则走本地体验模式），不含任何密钥。
- **`docs/stage3-cloud-setup.md`**：5 分钟图文步骤指南（iPhone 安装 Bark 取 Key + Supabase 建库部署函数 + 填 1 行 URL）。
